### New

- **Scale-dependent visibility reaches the web map.** A layer set to show only
  between two scales in QGIS now shows only between the matching zoom levels,
  for vector, raster and label layers alike.
- **Exports use OnlyMap 0.10.10.** A popup opened by a click now closes when you
  click away, and a legend entry shows its layer's own colour.
- **The Fidelity tab is grouped by layer, problems first,** with one summary
  line at the top and a button that takes you to where each fix is.
- **A Blocked item no longer stops the export.** Export and Host name each one
  and ask whether to go on without it.

### Fixed

- Restyling a layer while the dialog is open now marks the Fidelity report out
  of date instead of exporting the old style.
- A map taken down in the dashboard can be published again, as a new map.
- Labelling a 3D polygon layer no longer aborts the whole export.
- Relief maps no longer show an "API KEY REQUIRED" watermark.

The full list is in the changelog on the documentation site.
