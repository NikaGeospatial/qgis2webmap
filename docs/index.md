# QGIS2WebMap by NIKA

**Turn a QGIS project into a portable OnlyMap web map.**

Export a finished QGIS project to an interactive map that opens locally. No
account, no web server, no coding. The default export is a **single HTML file**
another person can double-click and use without QGIS installed.

> Exported maps contain **no tracking** and make **no network requests**. An
> exported file works with no internet connection.

## In short

1. Build and style your map in QGIS as usual.
2. **Web → QGIS2WebMap by NIKA → Create web map**.
3. Give the map a name, tick the layers to include, and press **Export**.
